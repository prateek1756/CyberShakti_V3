# CyberShakti v3 — AI-Powered Digital Safety & Cybersecurity Platform

> **CyberShakti** is an AI-powered digital safety and cybersecurity platform designed to help users identify, understand, and respond to online threats, digital fraud, and scams.

---

## 🌟 Master System Architecture & Feature Pillars

CyberShakti is organized around four primary product pillars serving 14 integrated features:

1. **Detect & Analyze**:
   - **F-01**: Phishing Link Scanning
   - **F-02**: Message & Email Scam Detection
   - **F-03**: Screenshot Scam Scanner
   - **F-04**: QR Code Scam Scanner
   - **F-05**: Fake Profile Verification
   - **F-06**: Deepfake Detection *(Research/Experimental)*
   - **F-07**: Mule Account Detection *(Research/Experimental)*
2. **Protect**:
   - **F-08**: Scam Call Blocking (Threat Lookup)
   - **F-09**: Password Security Checker
   - **F-10**: Secure File Encryption (AES-256-GCM)
3. **Assist & Respond**:
   - **F-11**: AI Cybersecurity Assistant (RAG Pipeline)
   - **F-12**: Cyber Risk Score Engine
   - **F-13**: Location-Based Scam Alerts (PostGIS)
4. **Learn & Prevent**:
   - **F-14**: Cyber Safety Hub (Tips, Quiz, Awareness Articles)

## 🛠 Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Axios, Recharts
- **Backend**: Python 3.11+, FastAPI, Pydantic v2, Uvicorn, Celery, Redis
- **Database**: PostgreSQL 15+ (`pgvector` & `PostGIS` extensions)
- **ML / Deep Learning**: PyTorch, DistilBERT, Scikit-Learn, XGBoost, PaddleOCR, NetworkX
- **Security & Crypto**: Argon2id, AES-256-GCM, JWT, TOTP 2FA
